# TravelAgentAPI

A simple FastAPI project for travel planning and booking.

## Run locally

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start the server:

```bash
uvicorn main:app --reload
```

3. Open the docs:

- http://127.0.0.1:8000/docs
- http://127.0.0.1:8000/redoc
